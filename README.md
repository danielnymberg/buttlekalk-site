# Buttlekalk AB – Webbplats

Statisk webbplats för [Buttlekalk AB](https://buttlekalk.se), Gotland.

## Stack
- Ren HTML/CSS
- Google Fonts (Noto Sans)
- Cloudflare Pages för hosting

## Lokal utveckling
Öppna `index.html` i webbläsaren, eller:
```bash
npx serve .
```

## Deploy
Koppla GitHub-repot till Cloudflare Pages. Ingen build krävs – output directory: `/`.
